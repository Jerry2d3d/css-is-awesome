# Code of Conduct

The **css-is-awesome** project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code-of-conduct/) as its code of conduct. The full text of the Covenant governs behavior in this project; this document summarizes the adoption and provides project-specific reporting and enforcement details. If anything below appears to conflict with the Covenant, the Covenant prevails.

By participating in this project — whether as a contributor, maintainer, reviewer, or community member — you agree to abide by the Covenant and the project-specific notes in this file.

## Scope

This Code of Conduct applies to all project spaces, including:

- The [css-is-awesome GitHub repository](https://github.com/Jerry2d3d/css-is-awesome) and its source tree
- Issues, pull requests, code reviews, and commit discussions
- GitHub Discussions and any other official discussion channels
- Any other venue (chat, social media, events) where a person is representing the project

It also applies when an individual is officially representing the project in public spaces — for example, by using an official project email address, posting via an official account, or acting as an appointed representative at an online or offline event.

## Our Standards

We aim to make css-is-awesome a welcoming, productive space for contributors of all backgrounds and experience levels. Contributors are expected to:

- Contribute constructively and keep feedback focused on the work
- Be welcoming and patient with newcomers and maintainers alike
- Assume good faith and ask clarifying questions before escalating
- Give credit where credit is due, including for prior art and inspiration
- Accept feedback gracefully and offer it the same way
- Respect differing viewpoints, experience levels, and design preferences

For the full list of expected behaviors — and for the examples of unacceptable behavior — please read the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code-of-conduct/) directly.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please report it through one of the following channels:

- **Email (primary):** jhansenportfolio@gmail.com
- **GitHub:** open a [private security advisory](https://github.com/Jerry2d3d/css-is-awesome/security/advisories/new) on the repository, or send a direct message to **@Jerry2d3d** on GitHub

When reporting, please include (as much as you are comfortable sharing):

- A description of what happened
- When and where it occurred (links to issues, PRs, or messages if applicable)
- Any supporting context, screenshots, or prior history
- Whether you would like to remain anonymous to the other party

All reports will be handled with discretion. Your identity and the details of your report will not be shared outside of what is necessary to investigate and respond. If a reported issue involves a project maintainer, the report will be routed to an uninvolved party whenever possible.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct. After reviewing a report, maintainers may:

- Edit, remove, or reject comments, commits, code, issues, pull requests, or other contributions that are not aligned with this Code of Conduct
- Issue private or public warnings
- Temporarily or permanently ban any contributor from the project's spaces for behavior they deem inappropriate, threatening, offensive, or harmful

Enforcement decisions follow the **Community Impact Guidelines** outlined in the Contributor Covenant — see the [enforcement ladder in Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code-of-conduct/#enforcement-guidelines) for the response tiers (correction, warning, temporary ban, permanent ban). Maintainers will apply those tiers based on the severity and pattern of the behavior.

Maintainers who do not follow or enforce the Code of Conduct in good faith may face temporary or permanent consequences as determined by other members of the project's leadership.
