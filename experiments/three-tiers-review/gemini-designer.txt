CONTEXT: A solo developer (Jerry) is building 'css-is-awesome' — a mixin-first SCSS design system. v1.0 has tokens, 6 themes (one-file swap), 120+ mixins, React components with CSS Modules, utility classes (cia- prefix), and as of today an opt-in bare-tags recipe.

He just removed BEM from every doc/example/internal style file. The new canonical authoring story has three tiers, all sharing ONE source of truth (the `btn(variant)` router mixin):

==========================================
TIER 1 — Drop-in CSS + HTML (no build)
==========================================

  <link rel="stylesheet" href="css-is-awesome.min.css">
  <link rel="stylesheet" href="theme-sketchbook.css">

  <main class="cia-container">
    <h1>Welcome</h1>
    <a class="cia-btn-primary" href="/start">Get started</a>
    <a class="cia-btn-outline" href="/docs">Read docs</a>
    <article class="cia-card">
      <h4>Sketchbook theme</h4>
      <p>Warm paper, sumi ink, indigo accent.</p>
    </article>
  </main>

One class per element. NO BEM (no btn--primary, no card__title). One CSS file, one theme file.

==========================================
TIER 2 — SCSS mixins + HTML (with build)
==========================================

  // app.scss
  @use 'css-is-awesome/scss/components/buttons' as b;
  @use 'css-is-awesome/scss/components/data'    as d;

  .hero-cta {
    @include b.btn(primary, $px: 6, $r: full);
    @include m.elevation(2);
  }
  .checkout-cancel { @include b.btn(outline); }
  .product-card    { @include d.card-base($shadow: 2); }

  <!-- HTML -->
  <a class="hero-cta" href="/buy">Buy now</a>
  <a class="checkout-cancel" href="/cart">Back to cart</a>
  <article class="product-card">…</article>

Author names their own classes (domain words like `hero-cta`, `product-card`). Mixin handles variant via an arg, not a class modifier.

==========================================
TIER 3 — Bare tags + opt-in recipe (no classes)
==========================================

  // app.scss — one line styles the whole site
  @use 'css-is-awesome/scss/recipes/bare-tags';

  <!-- HTML -->
  <h1>Welcome</h1>
  <button>Save</button>
  <table>…</table>
  <input type="email">

Pico-mode. Zero classes. Recipe styles every common bare tag. Override anything with any class-based selector and it wins automatically.

==========================================
SAME BUTTON ACROSS ALL THREE TIERS
==========================================

  Tier 1: <button class="cia-btn-primary">Save</button>
  Tier 2: <button class="save-btn">Save</button>      .save-btn { @include b.btn(primary); }
